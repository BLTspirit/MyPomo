# MyPomo

A Pomodoro timer built with C# and WPF.

## Planned Features
- Start, pause, and reset the timer
- Dual focus and break timers
- Customizable timer durations
- Auto-start next timer option
- Notifications for timer completion
- Alarm sound selection and volume control
- Background noise options for focus sessions
- Custom color themes including dark mode
- Dynamic taskbar icon to show remaining time
